## 三、这一轮做了什么

### 3.1 C++：只认虚表 RVA，多路径解析（`plugin/src/SAQ_UI.cpp`）

* 离线量出两个"全 exe 唯一"的身份判据（`tools/re/rtti_slots.py`）：
  `MovieImpl` 主虚表 RVA `0x3BCFEE8`、`AS3::MovieRoot` 主虚表 RVA `0x3BE32B0`
  （`[39]=0x3368DC0 Invoke`）；对象首个 qword 与它们一比就定性，零误判；
* 解析链：`IMenu(值+0x00)` → `0x68 = menuObj._objectInterface`
  （`[+0x08] = MovieImpl*`，GFx SDK 的 `ObjectInterface::movieRoot`）→
  在 MovieImpl 前 `0x4000` 字节里按虚表比对找 ASMovieRoot；
  另有 `IMenu+0x88`(uiMovie)、`IMenu+0x78`(AS3 根对象)、ObjectInterface 自身等兜底路径；
* 调用前核对 `vtable[0x39]` 的 RVA **必须等于** `0x3368DC0`，不等就**拒绝调用**并 Reset；
* 失败时把每个候选偏移/地址/RTTI 全部写日志（下一轮一次就能定位）。

### 3.2 载荷改成"中英双语"（`SAQ_UI.cpp` / `SAQ.cpp` / `SAQ_UI.h`）

```
SAQ1
T\t可接任务\tAvailable
Q\t<FormID>\t<type>\t<中文名>\t<英文名>
```

`QuestEntry` 增加 `nameZh/nameEn`；C++ 不再判定语言（只把读到的 INI 值打进日志，
标"仅供参考"），并且新增"直接读 INI 文件"的兜底。

### 3.3 SWF：语言自判 + 运行时标题 + 内嵌回退数据（`ui/missionmenu/src/MissionMenu.as`）

* 标题不再用 `$SAQ_AvailableQuests` 这种原文 token：由 AS3 的常量
  `可接任务 / Available` 决定，**只要 SWF 覆盖生效，标题必然正确**；
* 语言判定用**引擎推来的 `QuestData` 任务名**（本地化文本，最可靠）：汉字⇒中文，
  拉丁⇒英文，假名/谚文⇒英文；
* 数据源双通路：C++ 推送优先，没有推送就用内嵌载荷（构建时拼进
  `SAQ_EMBEDDED_CHUNKS`）——**即使插件没加载/桥没通，tab 里也有 485 条数据**；
* 条目字段补全（`sDescription` 等）修掉 `MissionInfo.UpdateMissionInfo` 读
  `sDescription.length` 会抛 Error #1010 的隐患；
* 「全部」tab 的掩码改成 `0xFFFFFFBF`（去掉我们那一位），未接任务只在我们的 tab 里出现。

### 3.4 工具/构建

* 新增 `tools/re/xrefto.py`：扫 .text 里"RIP 相对引用某个 RVA"和"call 某个 RVA"的位置

  lrg 版由 `make_lrg_source.py` 生成后同样拼接）。
