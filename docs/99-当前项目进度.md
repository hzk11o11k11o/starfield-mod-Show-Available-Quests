## 二、这一轮做完的事

### 2.1 调研（结论都写进了 `docs/00-项目总览与技术方案.md`）

1. **UI 源码可得**：`Creation-Hub/Interface` 仓库有官方任务菜单的 AS3/XFL 源码
   （游戏版本 1.10.32.0 的重建版）。
2. **SWF 可改可编**：`missionmenu.swf` 用 **FFDec（JPEXS）** 反编译出 74 个 AS3，
   改完用 `-importScript <in.swf> <out.swf> <脚本目录>` 重编译 —— **已实测生效**
   （只替换改过的两个类，体积 713299 → 714535 B）。
3. **任务菜单内部结构**（来自 AS3 源码）：
   - tab = `MissionMenu.PopulateTabs()` 里的 `FilterInfoA[{text, flag}]`
   - 数据 = `BSUIDataManager.Subscribe("QuestData")` → `data.aQuests`
   - 列表过滤 = `MissionsList.filterMask` × 条目 `iType`
   - 交互 = `MissionMenu_ToggleTrackingQuest` 等 CustomEvent → C++
4. **C++ ↔ AS3 通道**（commonlibsf 全都有）：
   - `UI::GetSingleton()->GetMenuMovie("BSMissionMenu")` → `GFx::Movie` → `asMovieRoot`
   - `ASMovieRootBase::Invoke / CreateString / CreateObject / CreateArray / PushBack`
5. **任务数据**（离线实测）：
   - `Starfield.esm` 有 2077 条 QUST，其中 **520 条带 QTYP**（= 玩家可见任务）：
     Activities 186 / Mission 129 / SideQuest 118 / Factions 52 / MainQuest 35
   - 任务的"类型/派系"是 **KYWD 关键词**（`QuestType*` / `FactionType*`）
   - `FULL` = 字符串表 ID → 在 `starfield_en/zhhans.strings` 里查到中英文名
   - **CTDA 一律 32 字节**；`QSTA`（objective target）**可以指向 alias**
     （如 `Alias = 003 PrimaryRef`）—— 这对后续"引导"功能很关键
   - **84% 的非主线任务没有记录级条件**；只有 19 个任务是 `Start Game Enabled`
     => 「可接」这件事大多由**对话条件 / Story Manager** 决定，无法纯静态判定
