  归入以后的引导功能。

### 3.2 推送链路：三道保险（C++/AS3）

| 改动 | 位置 | 作用 |
| --- | --- | --- |
| **探针** `SAQ_Probe(载荷) -> "<长度>|<前24字符>"` | AS3（挂 root）+ C++ `ProbeAs3String` | 把「参数没送到 / 送到被弄坏 / 送到且正常」一次分清（日志 `探针:` 段） |
| **回退 + 诊断码** | AS3 `SetAvailableQuests` | 解析 0 条时**回退内嵌表**并返回 `-2`（`-1`=参数 null/空）；界面永不空 |
| **SetVariable 通路** | C++ `kAttempts` 新增 kind=1 | `SetVariable("SAQ_Payload") + Invoke("SAQ_ApplyPayload")`（无参）——绕开 Invoke 带参数链路，对照组+兜底 |

* `kAttempts` 现在是「3 通路 × 2 编码 × 路径」14 项，日志里 `VW:` 前缀 = SetVariable 通路。
* 调用 SetVariable 前核对虚表槽 `0x31`（commonlibsf 声明一致），失败即跳过。
