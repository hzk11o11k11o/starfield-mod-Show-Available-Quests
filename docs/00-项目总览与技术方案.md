# 00 · 项目总览与技术方案

> 2026-09-19 建立。项目代号 **Show Available Quests（SAQ）**。
> 基于 SFSE（Starfield Script Extender）制作。

## 一、要解决的问题

原版《Starfield》不会主动告诉玩家"哪里能接到任务"——玩家必须自己撞见 NPC / 走到任务板 / 触发事件。
任务菜单里也只显示**已经接到**的任务，接不到的任务完全不可见。

本 MOD 要做的是：

1. 在**原版任务菜单（`missionmenu.swf`）里新增一个 tab：可接任务**；
2. 列表内容 = **当前游戏进度下玩家还能接到的任务**（进度不满足的不显示）；
3. **只关注非主线**（排除主线任务）；
4. 只收**支线 / 势力 / 活动 / 事件**等"能做完"的任务；无限生成任务不显示，但**接取入口**（如任务板）可以显示；
5. **高度整合进原版任务系统**：可选中、可跟踪，能调用游戏的任务引导（HUD 蓝点 / 扫描仪路径线）引导到接取地点；
6. **支持中文 / 英文**。

## 四、已确认的关键技术事实

### 4.1 UI 源码与工具链（★ 本项目最重要的前置条件）

- Starfield UI 有**官方 AS3 源码**（重建版）：`https://github.com/Creation-Hub/Interface`
  （XFL 格式 + .as，README 说明由 Adobe Flash 编辑后发布 swf）
- `missionmenu.swf` 可以用 **FFDec（JPEXS）** 反编译出 74 个 AS3 脚本，
  且**重编译往返完全一致**（713299 B → 713299 B，已实测）；
  → 修改 AS3 后 `-importScript` 重新生成 swf 是可行路径。

### 4.2 任务菜单的内部结构（来自 AS3 源码 + 反编译验证）

| 概念 | 位置 | 说明 |
| --- | --- | --- |
| Tab 列表 | `MissionMenu.PopulateTabs()` | `FilterInfoA = [{text, flag}]`，flag = `1 << iType` |
| 菜单名 | `"BSMissionMenu"` | `GlobalFunc.CloseMenu("BSMissionMenu")` |
| 数据来源 | `BSUIDataManager.Subscribe("QuestData")` | `data.aQuests` 数组 |
| 列表过滤 | `MissionsList.filterMask` × entry `iType` | `EntryFilterCompare_Impl()` |
| 任务类型 | `Shared.QuestUtils` | ACTIVITY=0, MAIN=1, FACTION=2, MISC=3, MISSION=4, COMPLETED=5 |
| 条目结构 | `MissionsListEntry` | `IsMission()` = `hasOwnProperty("aObjectives")` |
| 跟踪交互 | `MissionMenu_ToggleTrackingQuest` | `{questID, instanceID}` → C++ |
| 地图交互 | `MissionMenu_PlotToLocation` / `ShowItemLocation` | `{questID, objectiveID}` → C++ |
| 列表条目字段 | `uID / uInstanceID / iType / iFaction / sName / bActive / bComplete / bFailed / bIsMiscQuest / aObjectives[]` | 详见 `MissionsListEntry.as` |

### 4.3 C++ ↔ AS3 通道（commonlibsf 已具备）

```cpp
// C++ → AS3
auto movie = RE::UI::GetSingleton()->GetMenuMovie("BSMissionMenu" /* BS MISSION MENU */);
RE::Scaleform::GFx::Value args[1];
movie->asMovieRoot->CreateArray(&args[0]);
//   ... 填数组 ...
movie->asMovieRoot->Invoke("SetAvailableQuests", &ret, args, 1);

// AS3 → C++
//   AS3 侧 dispatch 的 CustomEvent 由引擎 UI 事件系统送达（如 ToggleTrackingQuest）
//   或 asMovieRoot->CreateFunction(&fn, handler, userData) 注册函数给 AS3 调用
```

可用 API（`RE::Scaleform::GFx::ASMovieRootBase`）：
`Invoke` / `CreateString` / `CreateObject` / `CreateArray` / `CreateFunction` /
`SetVariable` / `GetVariable` / `SetVariableArray` ...

### 4.4 任务数据（离线实测）

- `Starfield.esm` 共 **2077** 条 QUST，其中 **520** 条带 `QTYP`（= 玩家可见任务）：
  | QTYP 关键词 | 数量 | AS3 iType |
  | --- | --- | --- |
  | `QuestTypeActivities` (0x000475F8) | 186 | 0 |
  | `QuestTypeMainQuest` (0x000475FA) | 35 | 1 |
  | `QuestTypeFactions` (0x000475FD) | 52 | 2 |
  | `QuestTypeSideQuest` (0x00047600) | 118 | 3 |
  | `QuestTypeMission` (0x001E2D30) | 129 | 4 |
- `FULL` = u32 **字符串表 ID** → 可在 `Starfield - Localization.ba2` 的
  `strings/starfield_en.strings` / `starfield_zhhans.strings` 中查到中英文名（已实测）；
  文本里可能含 `<Alias=xxx>` 占位符（由引擎运行时替换，MOD 侧需要兜底处理）。
- `CTDA` 一律 32 字节；`DNAM` 12 字节；
  别名/阶段/目标分别由 `ALID/ALST/...`、`INDX/QSDT/NAM2`、`QOBJ/QSTA` 描述。

### 4.5 引擎侧可用接口（commonlibsf）

| 需求 | 接口 |
| --- | --- |
| 遍历所有 quest | `TESDataHandler::GetSingleton()->formArrays[FormType::kQUST]` |
| 运行中的 quest | `BGSStoryTeller::GetSingleton()->runningQuests`（已定义） |
| 条件评估 | `TESConditionItem::IsTrue(ConditionCheckParams&)` / `TESCondition::CheckValue` |
| 菜单/电影 | `UI::GetSingleton()->GetMenuMovie("BSMissionMenu")`、`UI::RegisterSink<MenuOpenCloseEvent>` |

> ⚠️ `TESQuest` 在 commonlibsf 中**只有前置声明**，运行时状态（是否已开始/已完成）
> 需要本项目自己做 RE（见 docs/01）。
