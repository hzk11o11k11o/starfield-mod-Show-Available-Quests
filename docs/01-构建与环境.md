## 二、构建

```powershell
# 全流程（静态表 + DLL + SWF + 部署到 MO2）
& ".\tools\build-saq.ps1"

# 只重编 DLL + 部署
& ".\tools\build-saq.ps1" -SkipTable -SkipSwf

# 只重编 SWF + 部署
& ".\tools\build-saq.ps1" -SkipTable -SkipPlugin

# 只构建不部署
& ".\tools\build-saq.ps1" -SkipDeploy
```

> 注意：**不要**用 `pwsh -File tools\build-saq.ps1` 外层再套一层 pwsh（会被 IDE 的
> safe-delete 包装挡下来），直接 `&` 调用即可。

## 四、几处"踩过的坑"（改代码前请先读）

1. **commonlibsf 的头文件不自包含**：`RE/S/ScaleformGFxASMovieRootBase.h` 用到
   `Value` / `Movie` / `FunctionHandler`，**必须先 include**
   `ScaleformGFxMovie.h` / `ScaleformGFxValue.h` / `ScaleformGFxFunctionHandler.h`，
   否则报 C4430/C2061 一连串语法错误。
2. **不要 include `RE/E/Events.h`**：它的 `static_assert(sizeof(HitData) == 0xF0)` 在
   本项目里直接编译失败（缺 `HitData` 的完整定义）。需要 `MenuOpenCloseEvent` 时，
   改成每帧轮询 `UI::IsMenuOpen` 更省事（本项目的做法）。
3. **FFDec 的 `-importScript` 参数是"脚本目录"**，不是文件列表；
   直接把目录里**只放改过的脚本**（保持 `Shared/` 之类的相对路径），
   这样 SWF 里只有那几个类会被重新编译（体积只涨 1KB 而不是 13KB）。
4. **xEdit 的 Pascal 脚本必须纯 ASCII 且不能出现花括号**；
   取值要用 `GetEditValue()`（`GetElementEditValues(e, '')` 对叶子返回空串）。
5. `xSFEdit64.exe` 无头运行约 **5 分钟**（加载 1.4GB 的 Starfield.esm）；
   跑之前想清楚要导出什么，一次跑完。
